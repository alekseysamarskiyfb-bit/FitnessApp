# Fitness

Личный трекер: питание, вода, расписание, тренировки и вес. React + Vite, данные хранятся в localStorage.

```bash
npm install
npm run dev      # локальный запуск
npm run build    # сборка в dist/
```

Деплой на Vercel: импортировать репозиторий, настройки по умолчанию (Framework: Vite).
